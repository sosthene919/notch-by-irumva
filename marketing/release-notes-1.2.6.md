# Notch by IRUMVA 1.2.6

Notch by IRUMVA is a Dynamic Island-style desktop companion for Windows 11.

## Highlights

- Music controls and synced lyrics
- Timers, stopwatch, reminders, to-dos, and water tracking
- Battery, volume, Bluetooth, privacy, and Windows notification activity
- File shelf, clipboard history, launcher, calendar, and quick actions
- Light/dark themes, translucent and glass materials, display selection, and a configurable global hotkey
- Windows system-tray controls and a dedicated Settings window
- Local-first storage with secure Windows-native settings protection

## Download

Download `Notch by IRUMVA_1.2.6_x64-setup.exe` from this release. The installer is unsigned, so Windows SmartScreen may show a warning for a new publisher. Verify the SHA-256 hash in `SHA256SUMS.txt` before running it.
