# Installer

Output: `Notch by IRUMVA_<version>_x64-setup.exe` (Tauri NSIS bundle in `app/src-tauri/target/release/bundle/nsis/`; also copied to `release/<version>/install.exe`). `installMode: both` lets the user choose "install for me only" (per-user, no admin) or "install for all users" (admin, Program Files); per-user stays the no-admin path. `Publisher: Iwasaki Softwares` in `tauri.conf.json` so the entry appears in Windows Settings > Apps > Installed apps with DisplayName "Notch by IRUMVA". User data is never stored next to the program: settings, to-dos, reminders and shelf paths stay in `%APPDATA%\com.irumva.notch` and survive updates, restarts and Disk Cleanup.

- Install/uninstall hooks: `app/src-tauri/windows/hooks.nsh` (stops the process, removes the autostart Run value).
- Terms: `installer/TERMS_AND_CONDITIONS.txt` is wired in as `bundle.licenseFile`, so the NSIS wizard shows it as a licence page that must be accepted before installing. Section 3 makes the user solely responsible for what happens when and after installing and using the app; it incorporates (does not replace) the MIT licence in `LICENSE`. Standard template terms, not legal advice.
- Icon: `app/src-tauri/icons/icon.png` (512 px) / `icon.ico` (16-256 px) - Concept A, a rounded square with the pill cut into the top edge and one #007AFF dot; used for the app, the installer and the uninstaller (`bundle.icon`, `nsis.installerIcon`/`uninstallerIcon`).
- Wizard branding: `app/src-tauri/windows/installer-sidebar.bmp` (164x314) and `installer-header.bmp` (150x57) are flat solid-color panels with the original icon and no gradient, wired in as `nsis.sidebarImage`/`headerImage`.
- Credits: version metadata (`bundle.copyright`), About screen, README, LICENSE/NOTICE. Company: Iwasaki Softwares; principal credit: IRUMVA Sosthene. The stock NSIS finish page has no credit-text hook; no custom template is used.
- Delete-user-data: the stock Tauri NSIS template already shows an opt-in "Delete app data" checkbox on the uninstall confirm page. When checked it removes `%APPDATA%\com.irumva.notch` and `%LOCALAPPDATA%\com.irumva.notch` (incl. the WebView2 cache); unchecked (including silent `/S`) user data is kept. Verified in the generated `installer.nsi` and by the live uninstall below; the checked path itself is template-inspection-verified (the owner-drawn checkbox resisted UIA automation).
- Signing: no certificate yet (A5). Unsigned builds trigger SmartScreen; the release path is Authenticode + timestamping in `docs/UPDATING.md`.
- Verified 2026-11-12 on the dev machine (v1.0.0, Iwasaki Softwares build): wizard shows the `TERMS_AND_CONDITIONS.txt` licence page requiring “I Agree” before installing (screenshot: `test-artifacts/installer-license.png`), new pill icon in wizard/app; silent install (`/S`) → files in `%LOCALAPPDATA%\Notch by IRUMVA`, HKCU Uninstall entry (Publisher Iwasaki Softwares, DisplayVersion 1.0.0); installed `notch.exe` launches, stays running and closes cleanly; silent uninstall → `notch.exe`, uninstaller and uninstall key removed, user data kept by default (a pre-existing `notch.bad-*.exe` rollback quarantine in the folder is not an installer file and is left alone). Frontend tests: 79/79 pass.
